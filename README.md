# Exploratory-Data-Analysis-mini-project
Exploratory Data Analysis (EDA) on Netflix Movies &amp; TV Shows using Python, featuring a comparative case study on The Vampire Diaries Universe (TVD, The Originals, and Legacies)
Netflix & TVDU Exploratory Data Analysis

About the Project
This project explores trends in the Netflix catalog using Python in Google Colab. It covers data cleaning, preprocessing, and statistical visualizations, followed by a comparison of The Vampire Diaries, The Originals, and Legacies.

What's Covered
1. Data Cleaning: Handling missing values, removing duplicates, and formatting dates and runtimes.
2. Netflix Catalog EDA:
   - Share of Movies vs. TV Shows
   - Content added over the years
   - Top content-producing countries
   - Movie runtime distributions, Correlation Heatmap, Pair Plot, and Linear Regression
3. TVD Universe Comparison:
   - IMDb rating and season count comparison across TVD, The Originals, and Legacies
   - Top 10 characters ranked by total episode appearances across all three shows

Tools & Libraries Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Google Colab

Files in this Repo
- Netflix_Data_Set.CSV - General Netflix titles dataset
- TVD_Data_Set.CSV - Character and series dataset for the TVD universe
- Notebook (.ipynb) - Complete Google Colab code and charts
